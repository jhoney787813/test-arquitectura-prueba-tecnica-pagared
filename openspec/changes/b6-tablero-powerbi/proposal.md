# Proposal

## Why

La Parte B6 pide un tablero para Laura con ventas, transacciones, ticket
promedio, comparación por zona/producto y variación diaria. En macOS no hay
Power BI Desktop, así que se entrega el diseño, las medidas DAX, los datos
exportados y un prototipo funcional, como permite la prueba.

## What Changes

- Se exporta el modelo a CSV.
- Se documentan el modelo, las medidas DAX, la página, los filtros y la RLS
  opcional.
- Se genera un prototipo HTML autónomo con filtros y variación, y su captura.
- Se publica en GitHub Pages con un workflow automático.
- Quedan pendientes el `.pbix`, las capturas reales de Power BI y la RLS.

## Capabilities

### New Capabilities

- `tablero-ventas`: tablero de ventas con indicadores, comparativos y filtros.

### Modified Capabilities

Ninguna.

## Impact

- `parte-6-b6-powerbi/`: DAX, diseño, datos, HTML, captura y workflow.
- Sección 7 del informe y página publicada en GitHub Pages.
