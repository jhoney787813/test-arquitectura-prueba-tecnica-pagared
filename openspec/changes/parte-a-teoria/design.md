# Design

## Context

Las respuestas se apoyan en las decisiones reales de B1-B6: LEFT JOIN, NULL,
float vs. Decimal, esperas de Selenium, zona horaria de Jenkins, idempotencia,
secreto en Git, watermark incremental, SCD2 y automatización de procesos.

## Decisions

- **Formato**: respuesta directa, justificación y, cuando aplica, SQL o ejemplo.
- **Límite**: máximo ocho líneas de redacción por respuesta; los bloques de
  código no cuentan como redacción.
- **Trazabilidad**: cada respuesta se vincula con una decisión del repositorio.

## Risks / Trade-offs

- Algunas respuestas son opinables; se prioriza el criterio y la justificación
  sobre la longitud.
